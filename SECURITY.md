# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting flow for
[iamjr15/voicey](https://github.com/iamjr15/voicey/security/advisories/new).
If private reporting is unavailable, contact the repository owner privately.

Include the affected version or commit, a minimal reproduction, impact,
prerequisites, and any suggested mitigation. Please do not include credentials,
tokens, recordings, or other sensitive data in the report.

## Supported versions

Security fixes are applied to the latest published `voicey` version. Older
versions may be fixed at maintainer discretion.
